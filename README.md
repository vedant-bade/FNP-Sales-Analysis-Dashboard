
# Ferns & Petals (FNP) Sales Analysis Dashboard

## Overview
An Excel-based sales analysis project using the Ferns & Petals (FNP) dataset to analyze revenue, customer spending, product performance, and sales trends.

## Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers and Timeline Filters
- KPI Cards

## Key Insights
- **Total Revenue:** ₹35,20,984
- **Total Orders:** 1,000
- **Average Delivery Time:** 5.53 days
- **Average Customer Spending:** ₹3,520.98

## Analysis
- Monthly sales performance
- Revenue by product and occasion
- Top 10 cities by order volume
- Customer spending patterns
- Product popularity across occasions
- Order quantity and delivery time analysis

## Dashboard Preview
The Excel dashboard provides interactive visualizations with occasion slicers and date timeline filters to explore sales performance.

## Objective
To derive meaningful business insights from sales data and support better decision-making regarding products, occasions, and sales strategies.
